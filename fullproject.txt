# LaLiga Match Outcome Prediction System - Technical Documentation

## 1. Algorithms Utilized

The project employs a sophisticated Stacking Ensemble architecture, combining statistical modeling with machine learning techniques to achieve high-precision football predictions.

### A. Dixon-Coles Poisson Model
*   **Function**: A specialized statistical model for predicting football scorelines.
*   **Mechanism**: It treats the number of goals scored by each team as independent Poisson-distributed variables. It calculates "Attack Strength" and "Defense Weakness" for every team.
*   **Key Feature**: Includes a "time-decay" (half-life) parameter that prioritizes recent form over old data, and an independence correction factor to accurately model the higher frequency of draws in low-scoring games.

### B. XGBoost (Extreme Gradient Boosting)
*   **Function**: A high-performance gradient-boosted decision tree algorithm.
*   **Mechanism**: It builds trees sequentially, where each new tree attempts to correct the residual errors of the previous ones. It is used both as a primary classifier and as a meta-learner.
*   **Key Feature**: Captures complex non-linear relationships between team stats (e.g., ELO vs. xG) and handles feature interactions efficiently.

### C. Random Forest Classifier
*   **Function**: An ensemble learning method based on decision trees.
*   **Mechanism**: It constructs a "forest" of many decision trees during training and outputs the average prediction (probability) across all trees.
*   **Key Feature**: Excellent for robustness against outliers and preventing overfitting by using random feature subsets for each tree.

### D. Logistic Regression (Meta-Learner)
*   **Function**: A linear model used to combine the wisdom of multiple sub-models.
*   **Mechanism**: It takes the probability outputs from the Poisson, XGBoost, and Random Forest models as its "features" and learns the optimal weighting for each to produce the final outcome.
*   **Key Feature**: Acts as the "judge" that decides which model to trust more in specific scenarios.

## 2. Overall Working Mechanism

The project follows a rigorous five-stage pipeline designed to ensure data integrity and predictive accuracy.

### Step 1: Data Acquisition & Preprocessing
*   Fetches real-time match data, including scores, Expected Goals (xG), and ELO ratings via external APIs or scrapers.
*   Cleans and normalizes team names and dates to maintain consistency.

### Step 2: Feature Engineering (Zero-Leakage Design)
*   **Rolling Statistics**: Calculates "Form" indicators (Points Per Game, xG for/against, Goal Difference) over a sliding window (typically the last 5 matches).
*   **Temporal Consistency**: Strictly ensures stats are "shifted" so the model only sees data that was available *before* the match started, preventing "data leakage" (cheating by using future knowledge).
*   **Delta Features**: Computes the difference between teams (e.g., `elo_delta`, `ppg_delta`) to highlight the relative strength gap.

### Step 3: Training & Cross-Validation
*   **Walk-Forward Validation**: Instead of random splits, the system uses "Time-Series Split." It trains on the past to predict the "next" set of games, mimicking real-world usage.
*   **Class Balancing**: Uses sample weighting to ensure the model doesn't ignore "Draws," which are statistically harder to predict than wins or losses.

### Step 4: Stacking & Meta-Learning
*   The system generates "Out-of-Fold" predictions.
*   The Meta-Learner (XGBoost/LogReg) is trained on these predictions to understand when the Poisson model is better than the Random Forest or vice versa.

### Step 5: Probability Calibration
*   Applies **Isotonic Regression** (via `CalibratedClassifierCV`). This ensures that if the model says a team has a 70% chance of winning, they actually win approximately 70% of the time in historical testing.

## 3. Generated Outputs

The system provides a comprehensive set of metrics and insights for every prediction.

### I. Match Outcome Probabilities
*   **Home Win (%)**: Probability of the home team winning.
*   **Draw (%)**: Probability of a tie.
*   **Away Win (%)**: Probability of the away team winning.

### II. Confidence Assessment
*   **Rating**: Categorized as "High," "Medium," or "Low" based on the certainty of the primary prediction.
*   **Logic**: High confidence is typically assigned when one outcome significantly dominates the distribution.

### III. Most Likely Scoreline
*   Derived from the Dixon-Coles Poisson distribution (e.g., "2 - 1"). This provides a "tangible" prediction beyond just the win/loss outcome.

### IV. Model Transparency (Base Model Breakdown)
*   The output includes the raw predictions from each sub-model (Poisson, RF, XGB). This allows analysts to see if models are in agreement or if there is a conflict.

### V. Performance Diagnostics
*   **Log Loss & RPS**: Standard football betting metrics to measure how close the predicted probabilities were to the actual outcomes.
*   **Calibration Curves**: Visual graphs (saved as PNGs) that prove the reliability of the system's probability estimations.
